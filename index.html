Install GoviLink

GoviLink works as an app on your computer or phone. Install it once, then open it from its icon whenever you need it.

GoviLink is installed. Close this page and open GoviLink from its icon: the Start menu or desktop on a computer, or the home screen on a phone. Then sign in.
GoviLink is already installed on this device. Open it from its icon (Start menu or desktop on a computer, home screen on a phone) and sign in there.
Install on iPhone or iPad
  1. Open this page in Safari.
  2. Tap the Share button (square with an arrow).
  3. Choose Add to Home Screen, then Add.
  4. Open GoviLink from your home screen.
If the button above does not work
  1. Use Google Chrome or Microsoft Edge.
  2. Click the install icon at the right end of the address bar, or open the browser menu (⋮ or …) and choose Install GoviLink / Install app.
  3. On Android, tap the menu (⋮) then Install app.
